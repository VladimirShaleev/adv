typedef adv_source_t *(*) adv_import_callback_t(adv_utf8_t name, adv_uint32_t depth, adv_data_t data)

Callback that supplies source files to the compiler.

Called first when the compiler resolves an import. The callback may obtain the source in any way, including allocating it in memory or reading it from a file.

Parameters
[in]nameImport or source name requested by the compiler.
[in]depthImport nesting level; the primary source is at level zero.
[in]dataUser data specified when setting the callback.
Returns
Pointer to the requested source, or NULL to let the compiler continue searching the provided sources and file-system paths.
Note
The compiler reads and parses a returned source before calling adv_release_import_callback_t, if a release callback is set. The client does not need to keep the source data alive for the remainder of the compilation.

typedef void(*) adv_release_import_callback_t(adv_source_t *source, adv_data_t data)

Callback that releases a source returned by the importer.

Called immediately after the compiler has read and parsed a source returned by adv_import_callback_t. Use it to release memory or other resources associated with that source.

Parameters
[in]sourceSource to release.
[in]dataUser data specified when setting the callback.
