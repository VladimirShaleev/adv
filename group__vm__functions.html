Functions for Script Handling.

Functions for handling compiled VM scripts.

Note
Serialized script data is always stored in little-endian byte order
in the binary format. The vm_read_* helpers read the raw payload, convert it to the native byte order of the current host, and return
values in host-endian representation. In other words, callers always
receive vm_uint16_t, vm_uint32_t, vm_sint32_t, and floating-point values as native CPU-order values, while the on-disk format remains
little-endian for all int16, int32, and larger fields.

void vm_get_import_dirs ( vm_t vm,
vm_uint32_t * dir_count,
vm_utf8_t * dirs )

Retrieves import directories configured for the VM.

Copies the active module search paths into the caller-provided array. The caller is responsible for providing storage for dir_count entries.

Note
If dirs is NULL, the function does not write directory paths and instead fills dir_count with the number of available entries required to store the full list.
Parameters
[in]vmVM instance to query.
[out]dir_countNumber of directories returned, or the required count when dirs is NULL.
[out]dirsArray of UTF-8 directory paths, or NULL to query the required buffer size.
