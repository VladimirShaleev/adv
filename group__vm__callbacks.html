typedef vm_bytecode_t *(*) vm_import_callback_t(vm_t vm, vm_utf8_t module, vm_data_t data)

Import callback used to resolve module dependencies.

Called when the VM needs to load an external module by name. The callback must return a pointer to a bytecode block. The VM copies the bytecode for its own use while importing the module.

Note
If vm_release_import_callback_t is set, the VM calls it immediately after copying the bytecode and importing the module.
Parameters
[in]vmActive VM instance.
[in]moduleModule identifier to import.
[in]dataUser data passed to the importer.
Returns
Pointer to a loaded bytecode block, or NULL when import fails.

typedef void(*) vm_native_callback_t(vm_t vm, vm_thread_h thread, vm_native_h native, vm_uint16_t arg_count, vm_data_t data)

Native callback invoked by the VM.

Called when a registered native function is executed from script bytecode. The implementation receives the active VM instance, the calling thread, the native handle, the number of arguments passed, and any opaque user data associated with the registration.

Parameters
[in]vmActive VM instance.
[in]threadCalling thread context.
[in]nativeNative function registration handle.
[in]arg_countNumber of arguments supplied by the caller.
[in]dataUser data registered with the native function.
