enum vm_opcode_t

Virtual machine instruction opcodes.

Identifies operations encoded in a script's bytecode. Instructions may consume values from or push values onto the VM stack.

Enumerator
VM_OPCODE_NO_OPERATION 

Performs no operation.

VM_OPCODE_IMPORT 

Imports an external module.

VM_OPCODE_PUSH_TRUE 

Pushes boolean true onto the stack.

VM_OPCODE_PUSH_FALSE 

Pushes boolean false onto the stack.

VM_OPCODE_PUSH_INT 

Pushes an integer literal onto the stack.

VM_OPCODE_PUSH_FLOAT 

Pushes a floating-point literal onto the stack.

VM_OPCODE_PUSH_STRING_FROM_DATA 

Pushes a string literal onto the stack from the data block.

VM_OPCODE_PUSH_STRING 

Pushes a string literal onto the stack.

VM_OPCODE_PUSH_GLOBAL_BY_NAME 

Pushes the value of a global variable identified by name.

VM_OPCODE_PUSH_GLOBAL 

Pushes the value of a global variable identified by its operand.

VM_OPCODE_PUSH_LOCAL 

Pushes the value of a local variable identified by its operand.

VM_OPCODE_POP_GLOBAL_BY_NAME 

Stores the stack top in the global variable identified by name.

VM_OPCODE_POP_GLOBAL 

Stores the stack top in the global variable identified by its operand.

VM_OPCODE_POP_LOCAL 

Stores the stack top in the local variable identified by its operand.

VM_OPCODE_POP 

Removes the stack top.

VM_OPCODE_BOOL_TO_INT 

Converts the stack-top boolean to an integer.

VM_OPCODE_BOOL_TO_FLOAT 

Converts the stack-top boolean to a float.

VM_OPCODE_BOOL_TO_STRING 

Converts the stack-top boolean to a string.

VM_OPCODE_INT_TO_BOOL 

Converts the stack-top integer to a boolean.

VM_OPCODE_INT_TO_FLOAT 

Converts the stack-top integer to a float.

VM_OPCODE_INT_TO_STRING 

Converts the stack-top integer to a string.

VM_OPCODE_FLOAT_TO_BOOL 

Converts the stack-top float to a boolean.

VM_OPCODE_FLOAT_TO_INT 

Converts the stack-top float to an integer.

VM_OPCODE_FLOAT_TO_STRING 

Converts the stack-top float to a string.

VM_OPCODE_STRING_TO_BOOL 

Converts the stack-top string to a boolean.

VM_OPCODE_STRING_TO_INT 

Converts the stack-top string to an integer.

VM_OPCODE_STRING_TO_FLOAT 

Converts the stack-top string to a float.

VM_OPCODE_BITWISE_NOT 

Applies bitwise NOT to the stack top.

VM_OPCODE_LOGICAL_NOT 

Applies logical NOT to the stack top.

VM_OPCODE_NUMERIC_NEGATION 

Negates the numeric stack top.

VM_OPCODE_BITWISE_AND 

Applies bitwise AND to the top two stack values.

VM_OPCODE_BITWISE_OR 

Applies bitwise OR to the top two stack values.

VM_OPCODE_BITWISE_XOR 

Applies bitwise XOR to the top two stack values.

VM_OPCODE_LOGIC_SHIFT_LEFT 

Logically shifts the left operand left by the right operand's count.

VM_OPCODE_LOGIC_SHIFT_RIGHT 

Logically shifts the left operand right by the right operand's count.

VM_OPCODE_ARITHMETIC_SHIFT_LEFT 

Arithmetically shifts the left operand left by the right operand's count.

VM_OPCODE_ARITHMETIC_SHIFT_RIGHT 

Arithmetically shifts the left operand right by the right operand's count.

VM_OPCODE_ADD 

Adds the top two stack values.

VM_OPCODE_SUBTRACT 

Subtracts the top stack value from the preceding value.

VM_OPCODE_MULTIPLY 

Multiplies the top two stack values.

VM_OPCODE_DIVISION 

Divides the preceding stack value by the top value.

VM_OPCODE_MOD 

Computes the remainder of the preceding value divided by the top value.

VM_OPCODE_EQUAL 

Compares the top two stack values for equality.

VM_OPCODE_NOT_EQUAL 

Compares the top two stack values for inequality.

VM_OPCODE_LESS 

Tests whether the preceding value is less than the top value.

VM_OPCODE_LESS_EQUAL 

Tests whether the preceding value is less than or equal to the top value.

VM_OPCODE_GREAT 

Tests whether the preceding value is greater than the top value.

VM_OPCODE_GREAT_EQUAL 

Tests whether the preceding value is greater than or equal to the top value.

VM_OPCODE_CALL_NATIVE_BY_NAME 

Calls a native function by name.

VM_OPCODE_CALL_NATIVE 

Calls a native function by its operand.

VM_OPCODE_CALL_BY_NAME 

Calls a subroutine identified by name.

VM_OPCODE_CALL 

Calls a subroutine identified by its operand.

VM_OPCODE_RETURN 

Returns from the current subroutine.

VM_OPCODE_JUMP 

Unconditionally jumps to the target identified by its operand.

VM_OPCODE_JUMP_IF_FALSE 

Jumps to the target if the stack-top condition is false.

VM_OPCODE_YIELD 

Yields execution so another VM thread can run.

VM_OPCODE_WAIT 

Suspends the current execution until its wait condition is met.

VM_OPCODE_HALT 

Halts the current VM execution.

VM_OPCODE_COUNT_ENUMS 

Count of constants in the enumeration.

VM_OPCODE_MAX_ENUM 

Max value of enum (not used).
