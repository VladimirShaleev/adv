◆ adv_compiler_compile()

adv_result_t adv_compiler_compile ( adv_compiler_t compiler,
adv_utf8_t file,
adv_uint32_t source_count,
const adv_source_t * sources,
adv_options_t options,
adv_compilation_result_t * result )

Compiles a source file or in-memory source.

If file is not NULL and is not empty, it identifies the primary source file. Otherwise, the compiler takes the primary source from sources. If neither is provided, there is no source to compile.

Imports are resolved first through the importer configured with adv_options_set_importer, then through the entries in sources. If neither supplies the module, the compiler searches the file system, including the importing file's directory, the configured import directories, and the current working directory.

The returned adv_result_t reports whether compilation succeeded regardless of whether result is NULL. When result is not NULL, it receives a compilation result object containing diagnostic messages and, when available, the syntax tree and symbol table.

Parameters
[in]compilerCompiler instance.
[in]filePath to the primary .adv file, or NULL/empty to compile the primary source from sources.
[in]source_countNumber of entries in sources.
[in]sourcesIn-memory source files. May be NULL when source_count is zero.
[in]optionsCompilation options, or NULL to use default options.
[out]resultReceives the compilation result object, or may be NULL if detailed diagnostics and compilation data are not needed.
Returns
ADV_RESULT_SUCCESS on success, or an error result describing why compilation did not succeed.
Note
To compile entirely from memory, pass an empty file and provide the primary file in sources.

◆ adv_options_get_import_dirs()

void adv_options_get_import_dirs ( adv_options_t options,
adv_uint32_t * dir_count,
adv_utf8_t * dirs )

Gets the configured import directories.

Copies up to the supplied capacity of directory pointers into dirs. The strings are owned by the options object; the caller must not free them. Their addresses may change when adv_options_set_import_dirs is called, so make copies if they must be kept longer.

Parameters
[in]optionsOptions object to query.
[in,out]dir_countOn input, capacity of dirs when dirs is not NULL. On output, number of directory pointers written. If dirs is NULL, receives the total number of configured directories.
[out]dirsDestination array, or NULL to query the total count.
Note
When dirs is not NULL, at most the smaller of the input capacity and the configured directory count is written.
See also
adv_options_set_import_dirs

◆ adv_options_set_importer()

void adv_options_set_importer ( adv_options_t options,
adv_import_callback_t callback,
adv_data_t data )

Set import callback.

Used to resolve code sources, such as when the compiler encounters imports.

Parameters
[in]optionsTarget options.
[in]callbackCallback function.
[in]dataCallback user data.
Note
If set, the importer is queried before the sources passed to adv_compiler_compile. If it returns NULL and no matching source is found, the compiler searches the file system, including the importing file's directory, the configured import directories, and the current working directory.
A typical use of an importer is to load source code from memory or from a source that is not available through the file system.
