Functions for handling compiled VM scripts.

Note
Serialized script data is always stored in little-endian byte order
in the binary format. The vm_read_* helpers read the raw payload, convert it to the native byte order of the current host, and return
values in host-endian representation. In other words, callers always
receive vm_uint16_t, vm_uint32_t, vm_sint32_t, and floating-point values as native CPU-order values, while the on-disk format remains
little-endian for all int16, int32, and larger fields.

Detailed Description

Script file format and byte-order utilities for the virtual machine.

Defines the binary script header and section table, along with validation and byte-swapping functions. Multibyte values in the file, including section values and bytecode operands, are stored in little-endian byte order.
