◆ VM_API

#define VM_API

Controls symbol visibility for shared library builds.

This macro is used to control symbol visibility when building or using the library. On Windows (MSVC) with dynamic linking (non-static build), it expands to __declspec(dllimport). In all other cases (static builds or non-Windows platforms), it expands to nothing. This allows proper importing of symbols from DLLs on Windows platforms.

Note
Define VM_STATIC_BUILD for static library configuration.

◆ VM_PACKED_BEGIN

#define VM_PACKED_BEGIN

Opens a packed-structure region for compilers that support it.

Marks the following declarations as tightly packed to minimize struct padding on supported compilers. This is used for binary file headers and table layouts that must match a fixed on-disk layout.

Note
This macro is a compatibility helper and is intentionally left empty on compilers that do not require explicit packing directives.

◆ VM_PACKED_END

#define VM_PACKED_END

Closes a packed-structure region.

Restores the compiler's previous packing alignment after a VM_PACKED_BEGIN block.

Encodes version components into a single integer.

Combines major, minor, and micro versions into a 32-bit value:

  • Bits 24-31: Major version (0-255)
  • Bits 16-23: Minor version (0-255)
  • Bits 0-15: Micro version (0-65535) The encoded value can be compared numerically when each component is within its documented range.

    [in]majorMajor version number.
